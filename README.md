# Switch Combo MVP

Godot 4.x / GDScript で作った、外部アセット不要の見下ろし型アクション試作です。敵に攻撃を当て、攻撃中に交代して連携攻撃をつなげましょう。

## 起動方法

1. Godot 4.x をインストールします。
2. Godot のプロジェクトマネージャーで「インポート」を選び、このフォルダーの `project.godot` を開きます。
3. プロジェクトを開き、右上の実行ボタンまたは F6 ではなく F5 でメインシーンを実行します。

コマンドラインからは `godot --path /path/to/girl_2daction_mvp` でも起動できます。初回は Godot によるプロジェクトの読み込みが必要です。

## 操作方法

| キー | 操作 |
| --- | --- |
| WASD | 移動、攻撃の向き指定 |
| J | 通常攻撃。3段まで連続し、攻撃中の次の入力も短時間受け付けます |
| K | 周囲を攻撃するスキル。クールダウンはキャラ別です |
| Space | 移動方向へ回避。移動していない場合は向いている方向へ回避します |
| L | キャラ交代と同時に周囲へ連携攻撃。通常攻撃中にも交代できます |
| R | HP が 0 になった後、最初からやり直します |

ピンクの A は素早い連撃型、青の B は移動と攻撃が遅い代わりに高火力です。敵へのヒット数が画面の HIT COMBO として増え、しばらく当てないとリセットされます。通常攻撃の段数はこれとは別に管理され、交代後も一定時間内なら次の段から続けられます。敵は撃破後、上限数まで一定間隔で補充されます。

## 主なファイルと調整箇所

- `project.godot` / `scenes/main.tscn`: プロジェクト設定とメインシーンです。
- `scripts/character_stats.gd` と `resources/character_a.tres` / `character_b.tres`: 移動速度、各段のダメージ・ノックバック・攻撃時間、射程、スキル性能を管理します。キャラを追加するときは Resource を作り、プレイヤー側のリストと交代処理を拡張します。
- `scripts/player.gd`: 移動、通常攻撃の段数・先行入力、交代、スキル、回避、HP を管理します。コンボ受付時間、交代クールダウン、回避性能もここで調整できます。
- `scripts/enemy.gd`: 敵の追跡、HP、接触ダメージ、被弾、ノックバックを担当します。
- `scripts/game.gd`: 攻撃の当たり判定、ヒット数、敵の生成、仮エフェクト、カメラ、UI を担当します。ヒットストップと画面揺れの時間・強さ、敵の出現間隔を調整できます。

キー割り当ては `game.gd` の `_setup_inputs()` で Input Map に登録しています。将来ゲームパッドのイベントを同じアクションに追加できます。描画とゲーム上の位置は分かれているため、仮図形をスプライトに置き換えられます。

- 予備動作やヒット範囲の演出、効果音、アニメーションを追加する。
- ゲームパッド入力、操作設定、複数キャラの選択画面を追加する。
- 敵同士の押し合い、敵の種類、ウェーブやリザルトを追加する。
- 斜め見下ろしアートに合わせて描画順や足元の当たり判定を整える。
