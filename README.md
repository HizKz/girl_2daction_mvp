# Switch Combo MVP

Godot 4.x / GDScript で作った、外部アセット不要の見下ろし型アクション試作です。敵に攻撃を当て、通常攻撃でマークをつけ、交代して連携攻撃をつなげましょう。

## 起動方法

1. Godot 4.x をインストールします。
2. Godot のプロジェクトマネージャーで「インポート」を選び、このフォルダーの `project.godot` を開きます。
3. プロジェクトを開いて F5 を押し、スタート画面で Enter / Space / K または START を選びます。

コマンドラインからは `godot --path /path/to/girl_2daction_mvp` でも起動できます。初回は Godot によるプロジェクトの読み込みが必要です。

## 操作方法

| キー | 操作 |
| --- | --- |
| E / L / I / A | 移動（E: 左、L: 上、I: 下、A: 右）、攻撃の向き指定 |
| K | 通常攻撃。3段まで連続し、攻撃中の次の入力も短時間受け付けます |
| T | こはるは前方ダッシュ、澪は敵を遅くするフィールドを発動します |
| N | 移動方向へ回避。移動していない場合は向いている方向へ回避します |
| S | キャラ交代。対応するマークがあれば連携攻撃が発動します |
| R | HP が 0 になった後、最初からやり直します |

日向こはるは近接攻撃で星マーク、星宮澪は遠距離の矢で月マークをつけます。星がついた敵に対して澪へ交代すると範囲内の敵全員に追撃、月がついた敵に対してこはるへ交代すると最も近い1体へ飛び込みます。マークは3秒で消えます。HPとスキルの待ち時間はキャラごとに管理し、両方のHPが0になるとゲームオーバーです。プレイヤーは立ち絵を基に生成した正面ドット絵を表示します。方向別・動作別のドットは未制作で、左右反転と簡易的な上下動・突き出しで表現しています。敵とエフェクトは仮描画です。

攻撃中も交代できます。通常攻撃は1・2段目なら一定時間内に続きから出せます。Nの回避は既存試作の機能として残しています。

## 主なファイルと調整箇所

- `project.godot` / `scenes/title.tscn` / `scripts/title.gd`: プロジェクト設定とスタート画面です。`scenes/main.tscn` がゲーム本編です。
- `scripts/character_stats.gd`、`scripts/skill_data.gd`、`scripts/combo_attack_data.gd` と `resources/character_a.tres` / `character_b.tres`: キャラ、スキル、交代攻撃の初期値を管理します。`character_a` がこはる、`character_b` が澪です。
- `scripts/player.gd`: 移動、通常攻撃の段数・先行入力、交代、スキル、回避、HP を管理します。コンボ受付時間、交代クールダウン、回避性能もここで調整できます。
- `scripts/enemy.gd`: 敵の追跡、HP、接触ダメージ、被弾、ノックバック、マークを担当します。
- `scripts/projectile.gd`: 澪の矢の移動と命中を担当します。
- `sprites/koharu/idle_down.png` / `sprites/mio/idle_down.png`: 立ち絵を基に作成したプレイヤーの正面ドット絵です。
- `scripts/game.gd`: 攻撃の当たり判定、ヒット数、敵の生成、仮エフェクト、カメラ、UI を担当します。ヒットストップと画面揺れの時間・強さ、敵の出現間隔を調整できます。

キー割り当ては `game.gd` の `_setup_inputs()` で Input Map に登録しています。O24 など OS のキーボード配列に合わせて、物理位置ではなくキーの文字で判定します。将来ゲームパッドのイベントを同じアクションに追加できます。描画とゲーム上の位置は分かれているため、仮図形をスプライトに置き換えられます。

## 動作確認

1. こはるで敵の近くから K を押し、敵に星マークがついたら S を押します。澪の追撃が範囲内の星マーク付きの敵へ当たります。
2. 澪で敵に向かって K を押し、月マークがついたら S を押します。こはるが最も近い対象へ移動して追撃します。
3. T で2人それぞれのスキルを試し、被弾後に交代してもHPが個別に残ることを確認します。
4. マークのない状態で S を押すと、追撃なしで交代します。

自動テストはエディターでプロジェクトを一度読み込んだ後、以下を実行します。

```sh
godot --headless --path . --script res://tests/combo_test.gd
godot --headless --path . --script res://tests/heroine_test.gd
```

仮描画、操作感、実際のアート素材の見え方は手動での確認が必要です。
