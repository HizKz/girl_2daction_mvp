# ヒロインコンビ案：星路ひなたと水瀬しずく

高専祭の展示ステージで、迷い込んだ不思議な光を集めて回る二人。ひなたが流れを作り、しずくが受け取って決める。交代のたびに光の軌跡がつながり、短時間でもコンビの気持ちよさを感じられる構成です。

## 星路（ほしじ）ひなた

1. **学年・役割**：学園2年生。展示ステージの案内役で、思い立ったらまず動くムードメーカー。
2. **性格**：人懐っこく前向き。勢い余って失敗するが、困った人を放っておけない。
3. **口調**：明るく短い言葉が多い。「いっくよ！」「しずく、お願い！」
4. **外見**：短めの桃色ポニーテール、星型の大きなヘアピン、動きやすいショートジャケット。ドット絵では跳ねた髪と黄色いピンで識別する。
5. **テーマカラー**：コーラルピンクと明るい黄色。
6. **モチーフ**：流れ星、スニーカー、リボン。
7. **得意／苦手**：初対面の人への声かけと即興ダンスが得意。計画を細かく立てることと静かに待つことが苦手。
8. **プレイヤーに感じてほしいこと**：元気をもらい、一緒に飛び出したくなる親しみ。ピンチでもこちらを信じる姿に少しドキッとする。
9. **戦闘スタイル**：近距離を素早く動き、小さな隙に連撃を入れる。攻撃は軽めだが交代への起点に向く。
10. **通常攻撃**：星の軌跡を描く短い二連打から、くるっと回る蹴りへ。3段目は前へ一歩踏み込む。
11. **スキル**：「スター・ステップ」。短い距離を駆け抜け、触れた敵に軽い複数ヒットを与える。
12. **交代連携**：「星渡し」。画面端から斜めに飛び込み、周囲を星形に斬る。しずくの重い一撃の直後に使うと、散った光を拾い上げる演出になる。
13. **相方との関係**：段取り上手なしずくを頼りつつ、慎重すぎて立ち止まる彼女の手を引く。暴走して叱られるが、しずくの努力を誰より見ている。
14. **勝利時**：「やった！ しずく、見てた？」
15. **被弾時**：「いたっ、まだまだ！」
16. **立ち絵差分**：基本笑顔、得意顔、驚き、困り笑い、照れ、真剣。
17. **ドット動作**：待機、上下左右の移動、通常攻撃3段、スキル、回避、交代登場攻撃、被弾、勝利。方向数は MVP では上下左右を基本とし、左右は反転を検討。

## 水瀬（みなせ）しずく

1. **学年・役割**：学園3年生。展示ステージの音響と進行を担当する、慎重なまとめ役。
2. **性格**：落ち着いて観察力が高い。準備には厳しいが、ひなたの無茶に付き合ってしまう優しさがある。
3. **口調**：穏やかで簡潔。「慌てなくて大丈夫」「ひなた、次は私の番」
4. **外見**：濃い青緑のセミロング、片側の長い編み込み、雫形の髪飾り、ロングベスト。ドット絵では長い髪と縦長のシルエットで識別する。
5. **テーマカラー**：青緑と白銀。
6. **モチーフ**：水滴、音叉、波紋。
7. **得意／苦手**：音の調整と事前準備が得意。急な予定変更と、自分の気持ちを大勢の前で話すことが苦手。
8. **プレイヤーに感じてほしいこと**：頼れる安心感。普段は冷静なのに、ひなたやプレイヤーへの信頼が不意に言葉から漏れる可愛さ。
9. **戦闘スタイル**：踏み込みと振りはゆっくりだが、広めの攻撃と大きなノックバックで敵をまとめる。
10. **通常攻撃**：音叉を模した短杖で横払い、波紋を伴う広い薙ぎ払い、両手で振り下ろす重い一撃。
11. **スキル**：「リップル・レゾナンス」。足元に波紋を広げ、周囲の敵を押し戻す。
12. **交代連携**：「響きの受け渡し」。ひなたの軌跡へ飛び込み、重い一撃と同心円の衝撃波を放つ。軽快な連打の締めに映える。
13. **相方との関係**：ひなたの勢いを制御する役だが、彼女のおかげで予定外の楽しさを知る。ひなたの勇気を内心では尊敬している。
14. **勝利時**：「うん、いい連携だったね」
15. **被弾時**：「っ……まだ大丈夫」
16. **立ち絵差分**：基本微笑み、真剣、驚き、困り、照れ、ひなたに向ける柔らかな笑顔。
17. **ドット動作**：待機、上下左右の移動、通常攻撃3段、スキル、回避、交代登場攻撃、被弾、勝利。大振りの予備動作と武器の残像を明瞭にする。

## ゲームプレイ上の強み

ひなたの速い連撃で攻撃を始め、しずくへ交代して重い一撃で敵を押し返す流れは、初見でも役割と手応えを理解しやすい。逆の交代では重い攻撃の後をひなたが素早く追いかける。ピンクの星と青緑の波紋、短髪と長髪、軽快さと重さを対比し、キャラクター選択の意味を見た目と操作の両方で伝える。

掛け合い例：ひなた「道、作るね！」→ しずく「受け取った！」。逆の交代では、しずく「あとをお願い」→ ひなた「まっかせて！」。

## 初期 MVP の最低限の素材

- 各キャラのドット絵：待機、移動、通常攻撃3段、交代攻撃、被弾。スキルと回避は当初既存ポーズの流用でも可。
- 各キャラの立ち絵：基本1枚と、喜び・被弾の表情差分。会話演出を入れる場合のみ使用。
- 共通の敵ドット絵：待機／移動、被弾、撃破。
- 星・波紋の攻撃エフェクト各1種、共通のヒットと撃破エフェクト。
- 最低限の UI 用キャラ顔アイコン2種と、攻撃・交代・被弾の効果音。音声は MVP では任意。
